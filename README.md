## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们有一批需要显式释放的资源（文件句柄、缓冲区），手工释放经常漏或者提前释放。请从零实现一个引用计数资源管理组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持资源注册并返回可引用对象，每次获取引用计数递增，释放引用计数递减；2) 引用计数归零时自动释放底层资源，释放动作只执行一次；3) 重复释放同一个引用要抛出明确错误并指出该引用已经释放过；4) 支持弱引用观察：资源已释放后能通过统计或弱引用观察到对象被回收（给出证据）；5) 支持泄漏检测：超过配置时间仍未归零的引用要报告，包含注册位置；6) 并发安全：多线程并发获取与释放引用时计数必须精确，不得提前释放；7) 测试覆盖计数增减、归零释放一次、重复释放报错、泄漏报告、并发计数正确与释放后可回收证据；`mvn -q verify` 一条命令跑通。
